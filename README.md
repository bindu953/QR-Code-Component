
# QR Code Component – Frontend Mentor

## Project Overview

This project is part of the Frontend Mentor QR Code Component Challenge.

The goal was to build a responsive QR code card using HTML and CSS and match the provided Figma design as closely as possible.

## Technologies Used

- HTML5
- CSS(Flexbox, Media Queries, Border Radius)
- Google Fonts (Outfit)
- Media Queries

## Features

- Responsive QR code card
- Centered layout using CSS Flexbox
- Rounded corners for the card and image
- Styled heading and description
- Colors and fonts based on the provided style guide

## Project Structure

qr-code-component/
- index.html
- style.css
- README.md
- images/
  - image-qr-code.png

## How to Run the Project

1. Clone or download the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or a web browser.
4. View the QR Code Component.

## What I Learned

Through this project, I learned how to:

- Use semantic HTML elements to structure a webpage.
- Use Flexbox to center content horizontally and vertically.
- Apply CSS properties such as padding, margin, and border-radius.
- Use colors and fonts from a style guide.
- Create a responsive layout for different screen sizes.
- Use Figma designs as a reference when developing a webpage.

## Challenges Faced

One challenge was aligning the QR code card in the center of the page and matching the spacing between the image, heading, and description.

I resolved this by using CSS Flexbox and adjusting the padding and margins to closely match the Figma design.

## Reflection

This challenge helped me understand how to convert a Figma design into a webpage using HTML and CSS. It also improved my understanding of CSS layouts, spacing, and responsive design.
